# PRODIGY_ML_01

## House Price Prediction using Linear Regression

This project was developed as part of the Machine Learning Internship at Prodigy InfoTech. The objective of this project is to build a Linear Regression model capable of predicting house prices based on important features such as living area square footage, number of bedrooms, and number of bathrooms.

The model was trained using the House Prices: Advanced Regression Techniques dataset from Kaggle. Data preprocessing, feature selection, model training, prediction, and evaluation were performed using Python and Scikit-Learn.

### Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-Learn

### Dataset

House Prices: Advanced Regression Techniques (Kaggle)

### Features Used

* GrLivArea (Above Ground Living Area)
* BedroomAbvGr (Number of Bedrooms)
* FullBath (Number of Full Bathrooms)

### Target Variable

* SalePrice

### Machine Learning Model

* Linear Regression

### Model Performance

* Mean Absolute Error (MAE): 35,788
* R² Score: 0.634

### Project Workflow

1. Data Loading and Exploration
2. Feature Selection
3. Data Splitting (Training and Testing)
4. Linear Regression Model Training
5. House Price Prediction
6. Model Evaluation
7. Result Visualization

### Conclusion

The Linear Regression model successfully predicts house prices using selected housing features and achieved a reasonable prediction performance, demonstrating the practical application of regression techniques in real-estate price estimation.
